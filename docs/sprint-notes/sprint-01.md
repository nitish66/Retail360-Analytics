# Sprint 01 – Enterprise Data Warehouse Design

## Objective

Design the enterprise data warehouse before implementation.

## Completed

- [x] Business Requirements Document
- [x] Dimensional Model
- [x] Architecture Decision Records (ADR)
- [x] Star Schema Diagram
- [x] Data Dictionary

## Decisions Made

- Adopt Kimball dimensional modeling.
- Use a Star Schema.
- Use surrogate keys for all dimensions.
- Implement SCD Type 2 for Customer and Product dimensions.
- Standardize naming conventions for tables and keys.

## Deliverables

- Business Requirements
- Logical Data Model
- Star Schema
- Data Dictionary
- Architecture Documentation
